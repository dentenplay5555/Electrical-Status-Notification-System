# docs/ — เอกสารประกอบโครงงาน

เก็บเล่มรายงานวิจัย รายวิชา IS ฉบับเต็มและ diagram ที่ใช้ประกอบในรายงาน (ดูภาพรวมทั้งระบบที่ [README หลัก](../README.md))

## โครงสร้าง

```
docs/
├── Report/
│   ├── report.odt            # เล่มรายงาน IS ฉบับเต็ม (แก้ไขได้)
│   └── report.pdf            # เล่มรายงาน IS ฉบับ PDF
├── diagrams/
│   └── circuit/
│       ├── circuit.jpg       # ผังวงจรการต่ออุปกรณ์
│       └── circuit.drawio.html # ไฟล์ผังวงจร Draw.io
├── picture/                  # ภาพประกอบอื่นๆ
└── unofficial-documents/     # เอกสารและคู่มือประกอบเพิ่มเติม
```

## หมายเหตุ

- ไฟล์ `report.odt` เป็นเล่มรายงานหลักที่ใช้เขียนและจัดรูปแบบตามระเบียบโครงงาน IS
- แผนผังวงจรใน `diagrams/circuit/` สามารถเปิดแก้ไขได้ผ่านเว็บ [Draw.io / diagrams.net](https://app.diagrams.net)
- โครงงานนี้ครอบคลุมการตรวจจับอุปกรณ์ไฟฟ้ากระแสตรง (DC Load 3–9 V) ผ่านเซนเซอร์ INA219 เท่านั้น
