# docs/ — เอกสารประกอบโครงงาน

เก็บเล่มรายงานวิจัย รายวิชา IS ฉบับเต็มและ diagram ที่ใช้ประกอบในรายงาน (ดูภาพรวมทั้งระบบที่ [README หลัก](../README.md))

## โครงสร้าง

```
docs/
├── report/
│   └── IS-report.odt      # เล่มรายงาน IS ฉบับเต็ม
├── diagrams/               # diagram ที่ใช้อธิบายเพิ่มเติมจากเล่มโครงงาน
└── unofficial-documents/    # ไฟล์เพิ่มเติมจากรูปเล่มจริง
```

## หมายเหตุ

- ไฟล์ `IS-report.odt` เป็นไฟล์งานที่มีการแก้ไขอยู่เรื่อย ๆ ตามความคืบหน้าของโครงงาน
- diagram ในโฟลเดอร์ `diagrams/` ไฟล์หลายๆ รูปแบบสำหรับการนำไปใช้ที่สะดวก
